學習路線

不想只看懂、想真的上手？從 L0 一路練到 L4
L0先裝起來5 分鐘 · 讓 graphify 指令跑起來
安裝 CLI uv tool install graphifyy（PyPI 套件名是 graphifyy 雙 y，指令是 graphify） install.html 註冊 skill graphify install（預設 Claude Code）或 --platform opencode 指定其他平台 install.html
L1跑一次真的15 分鐘 · 對自己手上的一個專案建圖
對專案建圖 在專案裡輸入 /graphify .，產生 graphify-out/（graph.json + GRAPH_REPORT.md + graph.html） docs/how-it-works.html 看報告 打開 GRAPH_REPORT.md：god nodes、surprising connections、建議問題 docs/how-it-works.html 玩互動圖 用瀏覽器開 graph.html，點節點、搜尋、隱藏社群——本站有真實範例可玩 docs/worked.html
L2用圖取代 grep30 分鐘 · 三個查詢指令上手
query graphify query "什麼連接著 auth 與資料庫？"——自然語言問問題，回傳局部子圖 docs/code/cli.html path graphify path "UserService" "DatabasePool"——兩件事之間的最短路徑 docs/code/cli.html explain graphify explain "RateLimiter"——一個節點與它所有鄰居 docs/code/cli.html 讓助手一直用圖 graphify opencode install 等指令，把「先查圖」寫進 AGENTS.md / hook，不再想起來才用 docs/skill-files.html
L3讀懂原理1-2 小時 · 圖是怎麼建出來的
三遍處理 Pass 1 AST 抽取（免費）→ Pass 2 影音轉錄（本機）→ Pass 3 文件/PDF 語意抽取（LLM） docs/how-it-works.html 社群與信賴 Leiden 分群、EXTRACTED/INFERRED/AMBIGUOUS 信任標籤、0.55–0.95 信賴級距 map.html 七階段 pipeline detect → extract → build → cluster → analyze → report → export，每個模組一個函數 docs/architecture.html 效能與成本 71.5× token 節省怎麼來的、為什麼圖越大越省、LOCOMO 45.3% 基準怎麼測的 docs/benchmarks.html
L4讀源碼進階 · 本站最深的章節
CLI 指令層 cli.py 的 subcommand 架構，每個指令對應哪個模組 docs/code/cli.html 抽取 pipeline detect / extract / build / cluster 逐函數講解——AST 怎麼變成圖 docs/code/pipeline.html 語言抽取器 extractors/ 骨架與各語言實作，models / engine / resolution docs/code/extractors.html 分析與輸出 analyze / report / export / exporters，graph.html 是怎麼生成的 docs/code/analysis.html · docs/code/export.html 維運與安全 cache / dedup / ingest / watch / serve / security / validate docs/code/ops.html skillgen 與測試 技能檔怎麼從 fragments 產出、測試策略與 fixtures 設計 docs/code/skillgen.html · docs/code/tests.html
給自己的驗收題：L1 結束後，你能在自己專案跑一次並說出 god node 是誰嗎？L2 結束後，你能不看原始檔就回答「A 跟 B 怎麼接上的」嗎？L3 結束後，你能解釋 INFERRED 0.85 跟 0.75 的差別嗎？能答出來，就往下走。
