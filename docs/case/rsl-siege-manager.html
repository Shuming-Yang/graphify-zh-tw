案例簡介

一個真實世界的全棧網頁 app：FastAPI 後端 + React/Vite 前端 + Python Discord bot，全在一個 repo。它是 graphify 官方挑來示範「多語言全棧專案」的案例，包含完整的測試套件與 17 個 Alembic migrations。

這個案例的互動圖是上游完整抽取的產出（含跨語言語意解析），1886 節點、3876 邊、141 社群。我們直接收錄並做了中文界面版。

God Nodes 解說

  1. _make_siege() — 124 條邊
  2. _make_member() — 92 條邊
  3. _make_position() — 85 條邊
  4. SiegeMember — 78 條邊
  5. _make_building() — 64 條邊
  6. _make_group() — 60 條邊
  7. BoardPage() — 55 條邊
  8. makeSiegeMember() — 55 條邊
  9. PostsPage() — 37 條邊
  10. _session_with_siege_and_configs() — 35 條邊

有意思的是 god nodes 橫跨兩端：_make_siege() 等是 Python 測試/工廠函數（124 條邊），而 BoardPage()、PostsPage() 是 TypeScript 前端頁面。測試工廠成為最高度數節點，說明測試如何重度串接整個領域模型。

Surprising Connections 解說

  • PostPriorityResponse --uses--> PostPriorityConfig — 後端 post_priority_config.py 的 API 回應型別，被前端 posts.ts 使用。後端到前端的型別共用，跨語言顯現。
  • TestStartupValidation --uses--> MemberRole — 後端測試 test_auth.py 用到前端的 MemberRole 型別，揭露跨語言測試相依。

這些邊都是 INFERRED——graphify 的跨語言解析把「後端型別被前端引用」這種 grep 抓不到的關係串起來。
