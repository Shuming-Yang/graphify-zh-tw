Graphify 繁體中文教學站

把整個 repo（程式碼 · 文件 · 技能 · 測試 · 案例）做成中英對照的解說
Graphify 是一個開源工具：在你的 AI 程式碼助手中輸入 /graphify， 它會用 tree-sitter 在本機把整個專案（程式碼、文件、PDF、圖片）解析成一張 可查詢的知識圖譜——用「問問題、找路徑、解釋節點」取代「一個檔案一個檔案地 grep」。
🕸️ 概念地圖 Concept Map 節點、邊、社群、god-node、EXTRACTED vs INFERRED——一張圖看懂知識圖譜的所有核心概念，以及 graphify 的運作流程。 🧗 學習路線 Learning Path 從安裝到讀源碼的分層路線：L0 裝好、L1 跑起來、L2 讀圖、L3 讀原理、L4 讀源碼。 📦 安裝指南 Install Guide OpenCode / Claude Code / Cursor 等 17 個平台的安裝指令、延伸套件與疑難排解。 📚 文件教學 Documentation 翻譯並解說官方文件：運作原理、架構、基準測試、安全模型、RFC、技能檔結構。 🧩 程式碼對照 Code Walkthrough /graphify 主程式、/tools、/scripts、/tests 逐函數講解，每個函數一個收縮塊，中文解說配英文原始碼。 🎮 Worked Examples 實作案例 /worked 五個真實案例的產出展示，外加可實際操作的雙版本互動知識圖譜（英文 / 中文界面）。
